# Virtual Dice Game
=====================

A simple web application that simulates a dice game between two players. The game outcome is determined on page refresh.

## Features
------------

- **Random Dice Rolls**: Simulates dice rolls for both players on page load.
- **Game Outcome**: Determines and displays whether Player 1 or Player 2 wins based on the dice rolls.
- **Interactive Interface**: Uses HTML, CSS, and JavaScript to create an engaging user experience.

## Technologies Used
--------------------

- **HTML**: For structuring the content.
- **CSS**: For styling and layout.
- **JavaScript**: For generating random dice rolls and determining the game outcome.

## How It Works
----------------

1. **Page Load**: The JavaScript code runs on page load, simulating dice rolls for both players.
2. **Game Logic**: The code compares the dice rolls to determine the winner.
3. **Display Outcome**: The result is displayed on the webpage.

## Getting Started
-------------------

1. Clone the repository 
2. Open the `index.html` file in a web browser to play the game.
3. Refresh the page to simulate new dice rolls and see the updated outcome.
